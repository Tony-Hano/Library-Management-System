# Library Management System (Java)

![Java](https://img.shields.io/badge/Java-17%2B-blue)
![MySQL](https://img.shields.io/badge/MySQL-8.0-orange)
![Swing](https://img.shields.io/badge/GUI-Swing-yellowgreen)

A comprehensive desktop application for library operations management built with Java Swing and MySQL.

## Summary
- Developed a RESTful library management system using Spring Boot, following MVC architecture and HATEOAS principles. 
- Implemented CRUD operations for managing library resources with Spring Data JPA and connected the backend to a MySQL database. 
- Employed Java 21, Maven for dependency management, and designed layered architecture with Controllers, Services, Repositories, and Configuration classes.
